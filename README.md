# 🖼️ ENCS5343: Comparing Smoothing Filters on Noisy Images

## 📌 Overview
This repository contains my implementation of **Assignment #1: Comparing Simple Smoothing Filters with Advanced Filters on Noisy Images** for the **ENCS5343: Computer Vision** course at **Birzeit University**. The assignment focuses on evaluating different noise filtering techniques based on **noise removal effectiveness, edge preservation, computational efficiency, and kernel size effects**.

## 🛠 Features
- ✅ **Noise Generation:** Add Gaussian and Salt-and-Pepper noise with varying intensities.
- ✅ **Filtering Methods:**
  - Simple Filters: Box Filter, Gaussian Filter, Median Filter.
  - Advanced Filters: Adaptive Mean, Adaptive Median, Bilateral Filter.
- ✅ **Performance Metrics:**
  - Mean Squared Error (MSE) & Peak Signal-to-Noise Ratio (PSNR).
  - Edge Preservation using Canny Edge Detection.
  - Computational Time Analysis.
- ✅ **Kernel Size Effects:** Investigate how different kernel sizes impact filter performance.

## 📂 Contents
- 📜 **Python Code:** Implements noise generation, filtering, and performance analysis.
- 📊 **Results & Analysis:** MSE, PSNR, edge preservation, and computational efficiency comparisons.
- 📄 **Report:** Explanation of methodology, experimental setup, results, and discussion.
